Step 10

Motor Calibration

ESC calibration for vertical and cruise motors

10.1 Motor Calibration Overview
VTOL requires two separate calibrations: vertical motors (quad-mode) and cruise motors (plane-mode). Vertical motors must be calibrated on quadcopter firmware, cruise motors on plane firmware.
Critical: Remove propellers before all motor calibration. Propeller contact will cause injury.

10.2 Vertical Motor Calibration (Motors 5-8)

Method: Use separate quadcopter firmware on dedicated autopilot OR temporary setup on second flight controller

Quadcopter Firmware Calibration:

  1. Flash quadcopter firmware to temporary autopilot
  2. Map motors 5-8 to quad outputs 1-4
  3. Connect ESCs to motor outputs
  4. Go to: Initial Setup → Optional Hardware → Motor Test
  5. Test each motor individually (5% throttle)
  6. Verify correct rotation direction
  7. Record calibration completion
  8. Restore VTOL firmware to main autopilot

10.3 Cruise Motor Calibration (Motors 3 & M3)

Method: Can be done on VTOL firmware using throttle calibration
  1. Connect VTOL aircraft via USB
  2. Go to: Initial Setup → Motor Test
  3. Test output 3 (throttle) at 5%
  4. Verify smooth acceleration
  5. No audio error tones should occur
  6. Record final settings

PID Tuning for Cruise Flight

Stabilization and response tuning for cruise (fixed-wing) mode

12.1 PID Control Basics
PID tuning optimizes aircraft stability and control response. Includes proportional, integral, and derivative gains for Roll, Pitch, and Yaw axes.
Tuning Safety: Perform initial tuning in simulator or gentle outdoor tests with manual override ready

12.2 Roll Control (Aileron) PID

Parameter Default Recommended Description
RLL_P 2.0 2.0-2.5 Roll proportional gain
RLL_I 0.05 0.05-0.1 Roll integral gain
RLL_D 0.0 0.0-0.15 Roll derivative gain (damping)
RLL_RATE_P 0.15 0.15-0.25 Roll rate proportional
RLL_RATE_I 0.0 0.0-0.05 Roll rate integral
RLL_RATE_D 0.004 0.004-0.010 Roll rate derivative

12.3 Pitch Control (Elevator) PID

Parameter Default Recommended Description
PTCH_P 2.0 2.0-2.5 Pitch proportional gain
PTCH_I 0.05 0.05-0.1 Pitch integral gain
PTCH_D 0.0 0.0-0.15 Pitch derivative gain
PTCH_RATE_P 0.15 0.15-0.25 Pitch rate proportional
PTCH_RATE_I 0.0 0.0-0.05 Pitch rate integral
PTCH_RATE_D 0.004 0.004-0.010 Pitch rate derivative

12.4 Yaw Control (Rudder) PID

Parameter Default Recommended Description
YAW_P 1.2 1.2-1.8 Yaw proportional gain
YAW_I 0.02 0.02-0.05 Yaw integral gain
YAW_D 0.0 0.0-0.05 Yaw derivative gain
YAW_RATE_P 0.18 0.18-0.30 Yaw rate proportional

12.5 Tuning Methodology

Iterative Tuning Process:

  1. Start Conservative: Begin with low P gains (1.0-1.5)
  2. Test & Observe: Fly in manual mode, assess response
  3. Increase P: Increase P gain 10-20% per iteration until oscillations appear
  4. Back Off: Reduce P gain by 10-15% for stable operation
  5. Add Damping (D): Small D gain (0.05-0.1) reduces overshoot
  6. Integral (I): Minimal I gain for steady-state error correction
  7. Rate Controller: Tune after attitude controller stable
  8. Document Settings: Save all final parameters
